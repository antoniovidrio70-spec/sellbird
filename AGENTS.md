# Instrucciones para asistentes en HARVEST

## Contexto compartido

Al comenzar una conversación o tarea en este repositorio, leer `empresa.md` en la raíz antes de responder preguntas sobre la empresa o el proyecto. Consultar los archivos pertinentes referenciados allí. El usuario quiere recuperar la información guardada sin indicar el archivo en cada conversación.

La fuente compartida es la versión actual de la rama `main` de `antoniovidrio70-spec/sellbird`. Si se dispone del conector GitHub, consultar esa versión para evitar depender de una copia antigua. No sobrescribir cambios locales al actualizar una copia de trabajo.

## Guardado de información

El usuario ha autorizado guardar la nueva información que proporcione sobre la empresa y el proyecto en este repositorio. Actualizar `empresa.md` o archivos pertinentes y mantener referencias desde `empresa.md` cuando se creen otros documentos de contexto. Registrar las correcciones explícitas del usuario, sin inventar hechos.

Para que la información esté disponible en otras sesiones, guardarla en GitHub mediante el conector o un commit y push. Confirmar el guardado solamente después de comprobarlo leyendo la versión remota. Si no se dispone de acceso de escritura, explicar que el guardado compartido queda pendiente.

Este repositorio es público. No publicar secretos, credenciales, datos personales ni información confidencial; esas categorías requieren un destino privado.

## Límites

Estas instrucciones funcionan cuando la sesión carga este repositorio y lee su AGENTS.md. Seleccionar un entorno por nombre no demuestra que el repositorio esté cargado, actualizado o que exista memoria automática entre chats. Si falta acceso, explicar el impedimento sin afirmar que no existe información guardada.
